## `> what_is_this`

Interface criada para representar minha identidade profissional através de:

✔ design tecnológico  
✔ navegação fluida  
✔ responsividade manual  
✔ animações e microinterações  
✔ organização front-end profissional  

---

## `> main_features`

- layout totalmente responsivo  
- background animado com Canvas API  
- efeito de digitação dinâmico  
- modal interativo para projetos  
- renderização dinâmica de conteúdo  
- separação entre HTML, CSS e JavaScript
